Haketi iconography

Clear, expressive icons for everyday interface moments.

Phosphor’s regular weight is the core Haketi UI style: friendly, legible, and quiet enough to support the content.

System rules

Use one icon family and one visual weight per context. Default to 20–24px in controls and 28–32px in feature cards.

Use icons to clarify

Icons should reinforce an action, state, or category—not replace clear labels in high-stakes controls.

Continue to workspace

Keep the accent intentional

Use primary purple for active, interactive, or brand-forward moments. Use ink for neutral utility icons.
